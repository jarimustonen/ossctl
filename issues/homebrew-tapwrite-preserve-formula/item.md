# homebrew tap-write regenerates the whole formula, obliterating hand-maintained stanzas

## Description


## Context

Surfaced by the `/llm-review` (gemini/gpt/opus/deepseek) of the tap-write leg landed for
`homebrew-dist-brew-audit-fails` (commits 15dfbde, 607407e). Multiple reviewers flagged the same
design point.

## Problem

The engine's Homebrew **tap-write** path (`crates/ossctl-core/src/release/adapters/homebrew.rs`,
`run_tap_write`) updates an existing formula by **re-rendering the whole `Formula/<name>.rb` from a
Rust-only template** (`render_formula`) and overwriting it. Any hand-maintained content in the tap's
formula is silently obliterated on the next release:

- extra `depends_on` (non-Rust deps, `openssl`, …), `resource` blocks, `patch`es
- `caveats`, `service`, `post_install`, shell-completion installs
- `bottle` blocks, `conflicts_with`, architecture/platform conditionals, custom `test`

For ossctl's OWN tap this is a non-issue — its formula *is* the generated cargo template, byte-for-byte
except url+sha — which is why option 3 (full render) was the endorsed, correct shape for the immediate
goal. But `ossctl` is a reusable engine (issuectl/other cargo CLIs, and eventually non-cargo taps via
`homebrew-formula-non-rust`), so a tap with a hand-tuned formula would be clobbered.

## Options

1. **Surgical edit**: read the existing formula, replace ONLY the `url "…"` and `sha256 "…"` lines
   (fail closed on zero/multiple matches), preserve everything else. Closest to the manual fallback
   that url+sha-edited in place. More parsing-fragile.
2. **Ownership marker**: only full-regenerate when the formula carries an `ossctl`-generated marker
   (`# Generated by ossctl; template-version: N`); otherwise surgical-edit or refuse.
3. **Contract opt-in**: a `formula_management: ossctl-generated | preserve` knob; default preserve.

## Not now / scope

Out of scope for the audit-fix unit (which correctly shipped full-render for ossctl's own tap). File
for a decision before the engine is pointed at any tap whose formula is hand-maintained. Overlaps
`homebrew-formula-non-rust` (the template is also Rust-only today).
